# Tech Stack

Framework:
- Laravel
- Laravel Breeze
- Blade
- Tailwind CSS
- MySQL

Rules:
- Gunakan Blade + Tailwind untuk full custom UI.
- Jangan gunakan Filament di project baru ini.
- Gunakan existing database eco_bank_26.
- Jangan menjalankan migrate:fresh.
- Jangan drop table.
- Gunakan Spatie Laravel Permission untuk role dan permission.
- Business logic penting taruh di Service class.
