# Development Workflow

Urutan pengerjaan:
1. Setup Spatie role-permission.
2. Setup dashboard redirect based on permission.
3. Build custom Blade layout and dashboard.
4. Build community cash module.
5. Build bank sampah module gradually.
6. Build member/warga dashboard.
7. Build reports and export.

Do not code large features at once.
Always plan before coding.
Do not run migrate:fresh.
Do not drop existing tables.
